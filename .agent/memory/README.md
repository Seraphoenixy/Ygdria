# 动态候选记忆

本目录是 Ygdria 的动态记忆层。这里的内容默认只是“候选事实”，可信度低于根目录 [`AGENTS.md`](../../AGENTS.md)，不能单独作为长期项目规则或设计约束的依据。

## 记录规则

每条记录尽量包含：

- 观察日期与范围；
- 事实、推测或待确认问题的明确区分；
- 证据来源（代码路径、文档、测试命令、用户确认或多次观察）；
- 可信度：`低`、`中`、`高`；
- 下一步核验或失效条件。

每天只使用一个 `YYYY-MM-DD.md` 文件；同一天的新发现按主题追加到该文件，不要为每个任务创建新的记忆文件。任务历史、一次性测试结果、自动提取的文件清单、环境差异、性能观察和未确认的设计意图都应留在这里。

## 提升为权威记忆

1. 先把新发现记录在本目录，不直接修改 `AGENTS.md`。
2. 用实现、文档、测试结果、重复观察或用户确认交叉核对。
3. 只有在信息稳定、长期有用且表述足够简洁时，才把结论提炼到 `AGENTS.md`。
4. 提升后保留候选记录作为证据；过时或被反驳的候选事实标记为 `superseded`，不要静默删除历史。
