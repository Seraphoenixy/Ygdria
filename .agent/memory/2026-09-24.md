## 多选导出修复

状态：候选事实；待后续版本或用户验收后再考虑提升为权威记忆。

### 观察与根因

- 多选前的普通点击只保存在 `selectedPlacementId`，原实现的 `selectedPlacementIds` 只保存后续修饰键选择的条目；右键菜单导出只读取后者，因此普通选中的第一篇笔记会被漏导出。
- Markdown 导出把多篇正文拼成一个 `.md` 文件。重新导入时，单个 Markdown 文件会变成单篇笔记，导致多选导出的笔记数量和树层级丢失。

### 当前实现

- `apps/web/src/lib/tree-selection.ts` 统一解析单选和完整多选集合；复制、删除、拖拽、右键批量操作和导出共用该解析结果。
- 多笔记或包含多个节点的 Markdown 导出生成 ZIP，并写入 `!!!meta.json` 树描述；现有 ZIP 导入分支可以按标题、正文和父子层级恢复。
- 单笔记 Markdown 仍下载为 `.md`，JSON 导出格式保持不变。

### 证据与待确认

- 代码路径、现有 ZIP 导入逻辑和新增回归测试共同支持；可信度：中高。
- 已通过 Web 类型检查、Web 测试（67 tests）、Web 构建，以及根工作区类型检查、全量测试和 i18n 检查。
- 需要在真实浏览器中手动验证 Ctrl/Cmd/Shift 多选、右键导出和 ZIP 再导入。若后续确定 ZIP 是长期公开交换格式，应补充用户文档后再提升到 `AGENTS.md` 或详细设计文档。
