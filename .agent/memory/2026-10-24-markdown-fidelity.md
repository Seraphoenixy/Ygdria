# Markdown 保真改进

本轮修复编辑器源码视图、Markdown 导入导出与 ETAPI 共同使用的转换器；不直接改写用户笔记。

- 修复普通链接目标丢失、常见 marks 丢失、任务勾选与列表层级丢失、引用/换行/分隔线丢失。
- GFM 不能稳定表示的格式通过白名单 HTML 往返；表格使用真正的行列标签并保留合并、列宽及单元格内容。
- 使用 marked 局部词法扩展解析公式与内部引用，避免在代码中做整篇正则替换。HTML 解析用 htmlparser2，无 DOM 依赖，前后端共用。
- 转换器继续返回 warnings；Web 源码视图显示已本地化的保留/不支持格式提示。原生正文权威和保存/同步协议未变，无迁移。
- 既有围栏代码导入的末尾空行归一规则保持；有重要末尾换行的原生代码块用 HTML 导出以保留内容。
- 任意第三方 HTML/CSS、未知编辑器扩展不保证无损，仍通过 warnings 表达限制。

验证结果：新增 30 项编辑器保真测试及 1 项 ETAPI 读写往返测试；全工作区共 506 项测试通过，typecheck、build、lint 和 diff whitespace 检查通过。以整理前快照的 214 篇富文本笔记做只读往返验证，提取的文字逐字一致（包含空白、缩进及 CRLF），公式/内部引用/图片节点总数一致。该快照检查不等同于所有任意文档的 JSON 结构或完整视觉等价保证。
