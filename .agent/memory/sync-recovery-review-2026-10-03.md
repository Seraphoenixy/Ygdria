# 同步故障复现与改进（任务记录）

2026-10-03：逐项复现此前同步评审的五项问题，均属实。

- 快照会话丢失：续页错误返回 200 并创建新快照；批量正文错误回退实时库。新增 HTTP 回归测试修复为 409 SYNC_SNAPSHOT_EXPIRED，客户端以新会话从第一页最多重试两次。
- 冲突记录：实际 useSync 在上传拒绝后遇到下载断网，localStorage 中无冲突。改为各实际 push 子批次响应后立即持久化；后续失败不丢记录，持久化失败不推进游标。
- 游标补偿：实际 useSync 在已有本地游标且空增量时未调用远端 advance。改为每轮同步开始确认已应用位置。
- 正文超时：提取原桌面代理的请求流程，用本地 HTTP 服务先返回头后延迟正文，JSON 和二进制均未按期限中止。修复为读取完整响应后才清除计时器。
- 快照资源：确认后缓存未释放、空闲六分钟仍可读取、未限制字节数、每次正文请求重扫快照。修复确认释放、访问时过期检查、总共 256 MiB 序列化预算及一次性正文索引。预算不保证峰值内存，超预算单快照仍需以后改用磁盘或流式快照。

验证：服务端同步/端到端 58 项、web 同步 24 项、api-client 5 项、desktop 10 项通过，共 97 项。受影响五个包的类型检查及 i18n lint 通过。测试配置使用 native 加载与 threads worker，在沙箱内执行；常规递归检查的沙箱子进程启动失败，因此各包独立执行类型检查。
